# MOBAIL

מועדון מובייל

## המנטור שלי · [`mentor.html`](./mentor.html)

אפליקציית מובייל אישית (עברית, RTL) ללווי מסע של שנה לירידה במשקל ואורח חיים בריא — יעד של 40 ק״ג.

**קובץ בודד, ללא התקנה.** פותחים את `mentor.html` בכל דפדפן (גם בנייד). כל הנתונים נשמרים מקומית בדפדפן בלבד — פרטי לחלוטין.

מה יש בפנים:
- **אונבורדינג חכם** — מחשב יעד קלורי אישי ובטוח (נוסחת Mifflin–St Jeor) וקצב ירידה בריא (~0.75 ק״ג לשבוע).
- **מסך בית** — טבעת התקדמות ליעד, מעקב מים, סטטיסטיקות, והודעת בוקר מהמנטור.
- **מנטור תומך** — צ׳אט אמפתי בגישת CBT להתמודדות עם רעב, נפילות, פלאטו וירידת מוטיבציה.
- **היום** — צ׳ק־ליסט הרגלים יומי, מדד מצב רוח, ויומן אישי.
- **תזונה** — שיטת הצלחת, החלפות חכמות, סולם רעב ושאלות נפוצות.
- **מעקב** — יומן שקילה עם גרף מגמה, ומפת מסע של 12 חודשים עם אבני דרך.

> ⚕️ הכלי חינוכי ותומך בלבד ואינו מחליף ייעוץ רפואי. לירידה של 40 ק״ג מומלץ ללוות את התהליך עם רופא/ה ותזונאי/ת.
